
# ❤️ Heart Problem Data Analysis

## 📌 Project Overview
This project analyzes heart disease data using **Python**, **NumPy**, **Pandas**, and **Matplotlib** to uncover health patterns and visualize key indicators.  
The analysis helps in understanding risk factors and trends related to heart disease.  

---

## 🛠️ Technologies Used
- **Python** 🐍  
- **NumPy** 🔢  
- **Pandas** 📊  
- **Matplotlib** 📈  

---

## 📁 Dataset
- The dataset `heart.csv` contains health data of patients with features like age, sex, cholesterol, blood pressure, and more.  
- Download dataset: [Kaggle Heart Disease Dataset](https://www.kaggle.com/datasets/johnsmith88/heart-disease-dataset)  

---

## ⚙️ How to Run
1. Clone the repository:  
```bash
git clone <your-repo-link>
```
2. Navigate to the project folder:  
```bash
cd HeartProblemAnalysis
```
3. Install dependencies:  
```bash
pip install numpy pandas matplotlib
```
4. Run the analysis script:  
```bash
python heart_problem_analysis.py
```

## 📊 Features / Analysis
- Display dataset information and summary statistics  
- Check for missing values and clean data  
- Visualize important relationships:  
  - **Age vs Cholesterol** 🧬  
  - **Gender Distribution** 👨‍👩‍👧  
  - **Correlation Heatmap** 🔥  

---

## 💡 Key Insights
- ❤️ Higher cholesterol and older age increase heart disease risk.  
- 👨 Males show higher frequency of heart disease than females.  
- 🔥 Chest pain type 1 (typical angina) is strongly associated with heart disease.  
- 📊 Resting blood pressure (`trestbps`) and maximum heart rate (`thalach`) influence heart condition.  
- 🧠 Visualizations make it easier to understand the trends and risk factors.
